# TekadeAtmega

Firmware project for an **ATmega4809** built with **MPLAB X**, **XC8**, and **MPLAB Code Configurator (MCC)**.

## Overview

This repository contains a single-board firmware application with Microchip-generated support code under `mcc_generated_files/` and application logic in `main.c`.

From the current source, the firmware is responsible for:

- driving a segmented display
- updating a two-digit clock display
- reading keypad/encoder-style inputs
- reporting ignition and key switch changes over UART
- controlling indicator LEDs
- controlling Raspberry Pi power-related signals such as `RPI_RUN` and `BckConv_EN`
- reading an LDR value through `ADC0`

## Repository layout

- `main.c` - main application logic
- `mcc_generated_files/` - MCC-generated peripheral setup and drivers
- `nbproject/` - MPLAB X project metadata and generated makefiles
- `Makefile` - top-level MPLAB X make entry point
- `ATMEGA4809Test.mc3` - MCC configuration

## Toolchain and project settings

The checked-in MPLAB X project is configured for:

- target device: **ATmega4809**
- toolchain: **XC8 2.32**
- device pack: **ATmega_DFP 2.3.126**
- project name: **ATMEGA4809Test**

These values come from `nbproject/configurations.xml` and `nbproject/project.xml`.

## Building

This project uses MPLAB X generated makefiles. Typical builds are driven through MPLAB X, but the repository also includes a root `Makefile`.

Example:

```sh
make CONF=default build
```

Other available configurations include `Simulator`.

> Note: building in a fresh environment requires the Microchip XC8 toolchain and the ATmega device pack used by the project.

## UART command interface

`main.c` implements a simple line-based UART protocol at **115200 baud**. Commands are sent as a command followed by zero or more semicolon-separated arguments:

```text
<command>[;<arg1>[;<arg2>...]]\r\n
```

Observed commands in the current source:

- `0;<digits>` - update the display buffer
- `1;<value>` - set signal strength
- `2;<led>;<enable>;<freq>` - configure an LED
- `3;<YYYY-MM-DD HH:MM:SS>` - set firmware time
- `4;<value>` - set brightness factor
- `5;<value>` - set brightness test value
- `6;` - read LDR value
- `7;` - mark Raspberry Pi shutdown complete
- `8;` - set Raspberry Pi state to sleep
- `9;` - set Raspberry Pi state to active
- `A;<0|1>` - control `BckConv_EN`
- `B;<0|1>` - control `Backlight_EN`
- `C;` - read current time
- `D;<value>` - set key stroke interval

The firmware also emits UART messages for button, ignition, and keypad events.

## Notes

- Much of the peripheral setup is auto-generated by MCC; regenerate those files from `ATMEGA4809Test.mc3` when hardware configuration changes.
- The repository currently has no separate test suite or higher-level documentation beyond the source and MPLAB X project files.
